# API 与数据说明

接口与网页部署在同一域名下。示例基地址为 `https://shuyu.example.com`；本地使用 `http://127.0.0.1:8080`。POST 请求发送 `Content-Type: application/json`，跨站或不同协议的浏览器来源会被拒绝。不开放跨域读取权限。

## 接口列表

| 方法 | 路径 | 鉴权 | 行为 |
|---|---|---|---|
| GET | `/api/health` | 无 | 返回运行状态、投稿总数、已审核数与运行秒数，不返回投稿正文 |
| GET | `/api/notes` | 无 | 已通过的心得数组，不含 QQ |
| GET | `/api/draw/pool` | 无 | 已通过的完整信件数组，含自愿填写的 QQ |
| POST | `/api/notes` | 无 | 投递心得，新增状态固定为 `pending` |
| POST | `/api/login` | 密码 | 返回临时管理员 token |
| GET | `/api/admin/notes` | Bearer token | 完整投稿数组，含所有审核状态和选填 QQ |
| POST | `/api/admin/notes/:id/status` | Bearer token | 将状态设为 `pending`、`approved` 或 `rejected` |
| DELETE | `/api/admin/notes/:id` | Bearer token | 删除对应记录 |
| GET | `/api/admin/export` | Bearer token | 下载完整 JSON 数据 |
| POST | `/api/admin/logout` | Bearer token | 立即撤销当前 token |

后台请求头：`Authorization: Bearer <token>`。会话保存在服务器内存，12 小时不活动后过期，服务器重启后失效。令牌保存在浏览器当前会话存储中。读取审核请求体后、执行修改前再次检查令牌，退出登录会阻止尚未完成的审核请求写入。

## 投递字段

```json
{
  "name": "书友小林",
  "book": "小王子",
  "author": "圣埃克苏佩里",
  "content": "重读这本书后，我开始珍惜日常生活中那些容易被忽略的陪伴与关心。",
  "qq": ""
}
```

| 字段 | 必填 | 限制 |
|---|---|---|
| `name` | 是 | 去除首尾空白后 1–20 个 UTF-16 代码单元，可用昵称 |
| `book` | 是 | 1–50 个 UTF-16 代码单元 |
| `author` | 否 | 最多 30 个 UTF-16 代码单元 |
| `content` | 是 | 20–2000 个 UTF-16 代码单元 |
| `qq` | 否 | 留空或 5–12 位数字 |

所有字段必须为字符串；页面显示的“字数”与 JavaScript `length` 一致，emoji 可能占两个代码单元。请求体上限 32KB。

新投递返回 HTTP 201：`{"ok":true,"id":1234567890123}`。10 分钟内全部表单字段相同的重试返回 HTTP 200 和原 id，不新建记录。仅提交成功不意味着公开，仍需管理员审核。

状态更新请求体：`{"status":"approved"}`。登录请求体：`{"password":"你的独立管理员密码"}`。密码与令牌不得写进 URL、源码、Issue 或截图。

记录额外包含数字 `id`、`status` 和北京时间字符串 `time`。数组按 id 升序返回，前端按需显示最新内容。客户端不能指定新增记录的 id、状态和时间。

## 错误与缓存

错误响应统一为 `{"error":"中文说明"}`。

| 状态码 | 含义与处理 |
|---|---|
| 400 | JSON、字段或状态不合法，修改输入后再试 |
| 401 | 密码错误、未登录或令牌失效，重新登录 |
| 403 | 来源不合法，通过本站页面操作 |
| 404 | 路径或记录不存在 |
| 413 | 请求体超过 32KB |
| 415 | POST 数据不是 `application/json` |
| 429 | 登录/提交限流，或信箱达到容量上限；稍后重试或联系管理员 |
| 500 | 服务端异常，检查服务器日志 |
| 503 | 保存失败或服务重启；成功提示前数据未获确认，应保留表单重试 |

API 使用 `Cache-Control: no-store`，不通过 304 返回空正文。首页支持 gzip 和 ETag 校验。服务端只暴露明确列出的网页与接口路径，`.env`、`data/`、源代码和 `.git/` 不作为静态资源提供。

## 运维边界

当前提供全量数组，适合约 300 人的单次活动。全局提交令牌桶允许突发 200 次、持续约 50 次/秒；这些上限不是容量承诺。默认不启用学生提交的每 IP 限流，以免校园共用出口误伤。管理员登录另有限流。

部署脚本中的 nginx 覆盖客户端转发头，后端在回环地址上启用 `TRUST_PROXY=1`，据 `X-Forwarded-Proto` 检查 HTTPS 来源。直连后端时使用 `TRUST_PROXY=0`。增加 CDN 或其他代理层后，需要重新评估可信代理链。

接口不提供图片、附件、学生账号或私信服务。不要把拆信接口中的 QQ 当作私密信息，也不要将完整后台导出文件放进公开仓库。
